## Plans

`plans/` is reserved for active design and implementation plans only.

If a plan has shipped, been abandoned, or been replaced by another direction, move it to `archive/plans/`.

## Archive

`archive/` contains historical investigations and completed or superseded plans.

Use it for archaeology, not as the source of truth for current behavior.
